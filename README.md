## 🚀 About the Project

**TECH PRIX 2026** is an engineering hackathon focused on innovation, rapid prototyping, and the integration of hardware with intelligent software solutions.

Inspired by the world of motorsports and technological innovation, the event brings together student innovators, engineers, developers, and problem-solvers to design and build solutions for real-world challenges.

The hackathon encourages participants to explore embedded systems, IoT, industrial automation, robotics, artificial intelligence, and sustainable electronics.

Organized under **SPACE × ORBYTE**, Tech Prix provides an opportunity to transform creative ideas into functional prototypes through an intensive 8-hour development sprint.

## 🎯 Event Highlights

- **Event:** TECH PRIX 2026 – The Technology Grand Prix

## ⚙️ Installation & Setup

### Prerequisites

Make sure you have installed:

- Node.js (compatible with Next.js 16)
- npm
- Git
- Visual Studio Code (recommended)

### 1. Clone the Repository

```bash
git clone https://github.com/Jyotiransh07/Tech-Prix-2026.git
```

### 2. Navigate to the Project

```bash
cd Tech-Prix-2026/tech-prix-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:3000
```

### 6. Build for Production

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

## 📋 Rules & Guidelines

1. The hackathon follows an 8-hour development timeline.
2. Participants must bring their own laptops, hardware components, sensors, boards, and tools.
3. Previously developed hardware or code must be declared.
4. A substantial new feature must be developed during the event.
5. Open-source resources and AI tools are permitted, provided participants understand their implementations.
6. All participants must follow electrical, fabrication, and venue safety guidelines.
7. Projects must be submitted and demonstrated within the given deadline.
8. Plagiarism and misconduct are strictly prohibited.
